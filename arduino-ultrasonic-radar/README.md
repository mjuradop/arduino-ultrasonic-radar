# Arduino Ultrasonic Radar

A real-time radar visualization built using Arduino and Processing.
This project simulates a radar system by scanning distances with an ultrasonic sensor
and visualizing them on a PC interface.

## Technologies
- Arduino (C/C++)
- Processing (Java-based)
- Serial Communication

## Hardware
- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- Servo Motor

## How to Run
1. Upload `arduino/radar.ino` to Arduino
2. Connect Arduino via USB
3. Run `processing/radar_visualization.pde` in Processing
4. Watch the radar sweep in real time

## Why this project?
I built this project in my free time because I find embedded systems
and real-time visualization extremely fascinating.
